Documentación de la API - Blog Gamer

Esta es la API creada para el parcial de Aplicaciones Híbridas 1.

Endpoints principales

Auth

  • POST /api/auth/register — Registrar usuario
  • POST /api/auth/login — Iniciar sesión
  • GET /api/auth/profile — Ver perfil (requiere token)

Posts

  • GET /api/posts — Listar posts
  • GET /api/posts/:id — Ver un post específico
  • POST /api/posts — Crear post (requiere token)
  • PUT /api/posts/:id — Editar post propio (requiere token)
  • DELETE /api/posts/:id — Eliminar post propio (requiere token)

Comentarios

  • GET /api/comments/:postId — Obtener comentarios del post
  • POST /api/comments — Crear comentario
  • DELETE /api/comments/:id — Eliminar comentario propio
  • GET /api/comments/user/:id/count — Cantidad de comentarios de un usuario

Usuarios públicos

  • GET /api/users/:id — Perfil público del usuario
