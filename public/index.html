Documentación de la API - Blog Gamer

Esta API permite manejar usuarios, posts y comentarios para el proyecto Blog Gamer.

La base de datos de esta API está diseñada para soportar un sistema de blog donde los usuarios pueden publicar contenido, interactuar entre sí y mantener un historial de actividad. Su estructura se organiza en tres colecciones principales: usuarios, posts y comentarios, conectadas entre sí mediante identificadores únicos.


Usuarios (User): almacenan la información de cada persona registrada, incluyendo nombre de usuario, email y contraseña encriptada. Cada usuario puede crear posts y comentarios, y solo puede editar o eliminar su propio contenido.


Posts (Post): representan las publicaciones del blog. Cada post contiene título, contenido, fecha de creación y una referencia al usuario que lo creó. Esta relación permite mostrar los posts de un usuario y construir su perfil público.


Comentarios (Comment): permiten la interacción entre los usuarios dentro de cada publicación. Cada comentario guarda su contenido, autor, post asociado y fecha. Un usuario puede realizar múltiples comentarios, y un post puede acumular varios comentarios.


Autenticación

POST /api/auth/register

Registra un nuevo usuario en la plataforma.

Body:

{
  "username": "eze",
  "email": "eze@example.com",
  "password": "123456"
}

Respuesta:

{
  "message": "Usuario registrado correctamente",
  "token": "...",
  "user": { "id": "...", "username": "eze", "email": "eze@example.com" }
}

POST /api/auth/login

Permite iniciar sesión y obtener el token.

Body:

{
  "email": "eze@example.com",
  "password": "123456"
}

Respuesta:

{
  "message": "Login correcto",
  "token": "...",
  "user": { "id": "...", "username": "eze", "email": "eze@example.com" }
}

GET /api/auth/profile

Devuelve datos del usuario autenticado.

Headers:

Authorization: Bearer token

Posts

GET /api/posts

Obtiene todos los posts publicados.

Ver JSON

GET /api/posts/:id

Devuelve un post específico por ID.

Ver ejemplo

POST /api/posts

Crea un nuevo post (requiere token).

Body:

{
  "title": "Mi post gamer",
  "content": "Contenido del post..."
}

PUT /api/posts/:id

Edita un post propio.

DELETE /api/posts/:id

Elimina un post propio.

Comentarios

GET /api/comments/:postId

Obtiene todos los comentarios de un post.

Ver ejemplo

POST /api/comments

Crea un comentario.

Body:

{
  "postId": "ID_DEL_POST",
  "content": "Gran post!"
}

DELETE /api/comments/:id

Elimina un comentario propio.
