Documentación de la API - Blog Gamer

Esta API permite manejar usuarios, posts y comentarios para el proyecto Blog Gamer.

Autenticación

POST /api/auth/register

Registra un nuevo usuario en la plataforma.

Body:

{
  "username": "eze",
  "email": "eze@example.com",
  "password": "123456"
}

Respuesta:

{
  "message": "Usuario registrado correctamente",
  "token": "...",
  "user": { "id": "...", "username": "eze", "email": "eze@example.com" }
}

POST /api/auth/login

Permite iniciar sesión y obtener el token.

Body:

{
  "email": "eze@example.com",
  "password": "123456"
}

Respuesta:

{
  "message": "Login correcto",
  "token": "...",
  "user": { "id": "...", "username": "eze", "email": "eze@example.com" }
}

GET /api/auth/profile

Devuelve datos del usuario autenticado.

Headers:

Authorization: Bearer token

Posts

GET /api/posts

Obtiene todos los posts publicados.

GET /api/posts/:id

Devuelve un post específico por ID.

POST /api/posts

Crea un nuevo post (requiere token).

Body:

{
  "title": "Mi post gamer",
  "content": "Contenido del post..."
}

PUT /api/posts/:id

Edita un post propio.

DELETE /api/posts/:id

Elimina un post propio.

Comentarios

GET /api/comments/:postId

Obtiene todos los comentarios de un post.

POST /api/comments

Crea un comentario.

Body:

{
  "postId": "ID_DEL_POST",
  "content": "Gran post!"
}

DELETE /api/comments/:id

Elimina un comentario propio.

Usuarios

GET /api/user/:id

Devuelve el perfil público de un usuario.
